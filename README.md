## دانلود

آخرین نسخه از صفحهٔ [Releases](https://github.com/Sadraka/Pamador-pomodoro/releases) قابل دریافت است:

- **ویندوز**: فایل `pamador-x.y.z-windows-x64.exe`
- **اندروید**: فایل `pamador-x.y.z-android.apk` (اندروید ۷ به بالا)

## امکانات تایمر پومودورو پامادور

- دو حالت تایمر: تمرکز و استراحت کوتاه
- تنظیم زمان تمرکز از ۱ تا ۹۹ دقیقه یا انتخاب از پیشنهادهای سریع
- صدای سفارشی برای آلارم (فایل صوتی دلخواه یا صدای پیش‌فرض)
- ذخیرهٔ خودکار تنظیمات — هر چیزی که بچینید، بعد از بستن برنامه حفظ می‌شود
- دوزبانه: فارسی و انگلیسی
- در صورت پایان تایمر، پنجره از حالت کوچک‌شده برمی‌گردد (قابل تنظیم)
- مخفی‌شدن در سیستم‌تری؛ بستن پنجره تایمر را متوقف نمی‌کند

## اجرا و بیلد

پیش‌نیاز: [Node.js](https://nodejs.org)، [Rust](https://rustup.rs) و برای اندروید [Android Studio](https://developer.android.com/studio).

```bash
npm install

# حالت توسعه دسکتاپ — تغییرات به‌صورت خودکار اعمال می‌شود
npm run tauri dev

# بیلد نهایی دسکتاپ — `beforeBuildCommand` خودش فرانت را می‌سازد
npx tauri build --no-bundle
```

خروجی: `src-tauri/target/release/pamador.exe`

### اندروید

```bash
# ساخت فرانت و همگام‌سازی با پروژهٔ اندروید
npm run cap:sync

# اجرا روی دستگاه/شبیه‌ساز متصل
npm run cap:run

# یا باز کردن پروژه در Android Studio
npm run cap:android
```

بیلد release با `assembleRelease` امضا می‌شود؛ اطلاعات امضا از `android/keystore.properties` خوانده می‌شود (در مخزن نیست).

## ساختار پروژه

```
src/                  # فرانت مشترک (React)
  components/         # اجزای رابط کاربری
  hooks/              # اتصال به بک‌اند و پخش صدا
  i18n/               # ترجمهٔ فارسی و انگلیسی
  platform/           # لایهٔ انتزاع پلتفرم: Tauri / موتور JS تایمر
src-tauri/
  src/timer.rs        # منطق تایمر و ذخیرهٔ تنظیمات (دسکتاپ)
  src/lib.rs          # پنجره‌ها، تری و رویدادها
android/              # پروژهٔ Capacitor اندروید
```

## تایمر پامادور چطور کار می‌کند؟

روی دسکتاپ منطق تایمر در Rust اجرا می‌شود، نه جاوااسکریپت. یک نخ پس‌زمینه هر ثانیه وضعیت را بررسی و از طریق رویداد به فرانت اطلاع می‌دهد. روی اندروید همان رفتار با یک پیاده‌سازی TypeScript از همین منطق بازسازی شده — هر دو از deadline مطلق استفاده می‌کنند تا شمارش حتی با کندی سیستم دقیق بماند.
